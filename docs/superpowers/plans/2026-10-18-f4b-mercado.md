# F4b Mercado Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** A members-only "Mercado" section: `/mercado` lists the top 100 cryptos (CoinGecko) and `/mercado/[id]` shows one coin with a price chart (24h/7d/30d/1a) and key data, served from a server-side cache that survives API failures by showing the last good copy with its time.

**Architecture:** A small CoinGecko client (`src/lib/market/coingecko.ts`) fetches and strictly validates three endpoints. A cache layer (`src/lib/market/cache.ts`) keeps the last good payload per key in a service-role-only Supabase table `market_cache` and refetches only when the copy is older than its TTL (60 s list, 5 min coin/chart). If the refetch fails, the stale copy is returned with `stale: true` and its `fetchedAt`; with no copy at all, a typed error. Pages are dynamic server components (members only via the forum layout) inside `Suspense`, with hand-rolled SVG charts like `/dao`.

**Tech Stack:** Next.js 16 App Router (cacheComponents), Supabase (service role for the cache table), Vitest + RTL, pgTAP, Playwright with a local mock CoinGecko HTTP server.

**Spec:** docs/superpowers/specs/2026-10-18-f4-gobernanza-design.md (decision 11 and "Panel y páginas" §18).

## Global Constraints

- `/mercado` (lista) y `/mercado/[id]` (ficha), solo para miembros; entry "Mercado" in the top bar (desktop sections and mobile drawer, which share `sections()` in `src/components/shell/sidebar.tsx`), right after "DAO".
- Top 100 with: precio, variación 1h/24h/7d, capitalización, volumen y minigráfico de 7 días.
- Ficha: gráfico 24h/7d/30d/1a y datos clave.
- Caché en servidor de 60 s para la lista y de 5 min para los gráficos (and the coin detail).
- Atribución visible "Datos de CoinGecko" linking to https://www.coingecko.com (rel="noopener noreferrer", target _blank).
- Si la API falla, se muestra la última copia con su hora, o un error claro.
- Market numbers are display-only (never feed money logic): JS `number` is fine here; format with `Intl.NumberFormat("es-ES")`. Prices < 1 USD keep up to 6 significant digits; ≥ 1 USD two decimals; capitalización/volumen compact ("1,23 bill. USD" style via `notation: "compact"`).
- The market client is separate from `src/lib/treasury/valuation.ts`; never import market code from treasury code or vice versa.
- No new dependencies. Design tokens only; Lucide icons; ≥44 px targets; no horizontal scroll at 375 px; colour is never the only signal (sign + arrow/text for variations).
- Copy in Spanish.

## Review Focus

1. **CoinGecko down or rate-limited (429/5xx/timeout/malformed JSON) on first ever load** — expected: a clear error state with a "Reintentar" link, never a crash or an empty table pretending to be data. Test in Task 1 (typed error) and Task 2 (UI state).
2. **CoinGecko down after a good fetch** — expected: last copy shown with "Datos de las HH:MM (no se pudo actualizar)". Test in Task 1 and Task 2.
3. **Hostile or unknown `/mercado/[id]`** (`../`, uppercase, 200 chars, unknown coin → API 404) — expected: 404 page, no fetch for invalid ids, unknown id not cached as good data. Test in Task 1 and Task 3.
4. **Malformed rows** (null price, missing sparkline, non-https or foreign image host) — expected: the row still renders with "—" for the missing figure, no image if the URL isn't https on `coin-images.coingecko.com` / `assets.coingecko.com`. Test in Task 1 (validation) and Task 2.
5. **375 px** — expected: list shows rank, coin, price and 24h; other columns hidden below `md`; no horizontal scroll. Test in Task 4 (e2e scrollWidth).
